# 禾记原型设计与开发交接

版本：v0.2 · 日期：2026-11-04 · 类型：高保真可交互网页原型 + 独立视觉概念图；已补齐历史图表

## 1. 交付物与使用

- `prototype/index.html`：直接双击，用 Edge/Chrome 打开；桌面展示画布含导航说明，窄屏为手机界面。
- `design/sunburst-concept.png`：按用户指定的 GPT Image 2.5 Sunburst 技能生成的视觉探索，可能含生成文字或数值误差，只用于风格参考。
- `design/prototype-overview.png`：由真实运行的 HTML 原型截取，作为实现后视觉预览。
- `design/history-statistics.png`：历史年度、历史月份、历年账单的实际原型截图拼图；`prototype/index.html#charts-year` 可直达年图，`#charts-history` 可直达历年账单。
- `docs/需求与设计说明.html` / `docs/需求与设计说明.pdf`：适合浏览、打印和分享的合并文档；Markdown 为可维护源文件。

最终交互、文字和计算以 HTML 原型及 PRD 为准。AI 概念图不是逐像素开发规格，也不表示已有 APK。

## 2. 视觉规范

临时品牌“禾记”，寓意日常积累。采用暖白纸张、森林绿主色与少量杏色，减少金融仪表盘的压迫感，保持数字清晰。

| 令牌 | 值 | 用途 |
|---|---|---|
| background | #F7F8F2 | 主页面暖白底 |
| surface | #FFFFFF | 表单、卡片与覆盖层 |
| primary | #174E42 | 主按钮、品牌、选中态 |
| primary-soft | #E6EDDF | 图标底、轻提示 |
| text | #253B34 | 正文与金额 |
| muted | #67766D | 辅助说明 |
| accent | #EAC4A0 | 次级图表色 |
| danger | #B04435 | 删除、超支等需注意状态 |
| border | #E6E9E0 | 分隔与输入边界 |

字体使用系统中文无衬线，Windows 优先微软雅黑；数字使用支持等宽数字的系统字体。标题 22–28px，主金额 38–40px，正文 14–16px，辅助文字 12px；移动端正式实现按 sp/dp 转换并适配字体缩放。

间距以 4/8 为基准，页面横向 22px，主要卡片圆角 20–24px；主动作 48px 以上。图标用统一描边 SVG，避免把图标做成不可编辑的位图。全屏页面尽量一个主动作；危险操作始终配明确文字。

## 3. 页面与交互规格

| 页面 | 展示重点 | 交互与返回 |
|---|---|---|
| 总览 | 月份、深绿收支卡、预算卡、最近账目 | 换月同步明细/预算并更新图表基准日期；图表历史浏览独立；账目进入详情 |
| 记一笔 | 类型切换、醒目金额、类别网格、备注、日期、键盘 | 保存后返回来源；编辑模式回填；有修改关闭需确认 |
| 明细 | 月选择、搜索、过滤、列表/日历 | 日历点日期联动列表；空结果保留筛选 |
| 详情 | 类型与金额、类别、日期、备注 | 编辑进入记账表单；删除二次确认 |
| 图表 | 支出/收入、周/月/年、总额/均值、折线、分类排行 | 历史周期切换；选点看精确金额；年图下钻月图；同周期分类明细 |
| 历年账单 | 每年和每月的收入、支出、结余 | 展开年份；点击月行看当月图表；年份回看年趋势 |
| 预算 | 余量、进度、分类额度 | 总额与分类一次校验保存；超支不阻止记账 |
| 我的 | 本地数据状态、明细导出、备份恢复 | 文件下载真实可用；恢复前校验与确认；重置仅为演示工具 |

底部中间记账按钮对所有主页面可达。桌面侧栏提供快速跳转与调研文档链接，属于评审画布，不属于 Android 应用界面。

## 4. 演示数据与计算口径

原型日期固定为 **2026-11-04**，避免不同日期打开导致演示变化。月份可切换。首次打开加载虚构数据，保存、编辑、删除及预算修改写入当前浏览器的本地存储。

- 2026-11：收入 12,000.00 元，支出 2,310.00 元，结余 9,690.00 元。
- 当月总预算 5,000.00 元，剩余 2,690.00 元，已用 46.2%。
- 本月仍为 13 笔支出与 1 笔收入；额外提供 2024-01 至 2026-10 每月 6 笔历史演示，共 218 笔。历史记录是按类别构造的虚构样本，所有图表仍从实际账目实时生成。
- 2026 年支出 32,580.00；2025 年支出 35,972.00；2025 年 2 月支出 2,883.00，便于检查年图与月图下钻。
- 使用过 v0.1 的浏览器保留已有账目；若还没有历史账目，可在“图表 → 历年账单”点击添加历史演示并确认。追加不会覆盖已有账目，同 ID 不重复添加。
- 首次示例包括房租、餐饮、交通、购物等。金额仅为虚构演示，不代表真实财务建议。
- “日均可用”含 11 月 4 日当天，共 27 天，为 99.62 元（分单位向下取整）。

原型“恢复演示数据”会覆盖本浏览器的原型数据，操作需要确认。不要在原型中保存真实敏感账目；正式版必须通过私有数据库与持久化测试。

## 6. 建议评审路径

1. 总览核对 2,310.00 元支出与 46.2% 预算。
2. 点“＋”，选择餐饮，输入 32，保存；总览支出变为 2,342.00。
3. 打开该条账目并改成 28.50，确认统计同步；再删除，确认恢复初始值。
4. 在明细搜索“咖啡”，切换日历并选择 11 月 4 日；清除筛选后回到完整月份。
5. 在图表切换“年”，看 2026 年各月支出；点标题选 2025 年；点 2 月数据点并“查看本月”，核对 2,883.00 元。选择餐饮后核对同周期分类明细。
6. 调整预算，查看分类分配约束及超支状态。
7. 导出当前月 CSV 和完整 JSON；修改一笔后恢复 JSON，核对数据回到备份状态。
8. 进入“历年账单”，展开 2025 年，核对每月收入/支出/结余；点击月份回到对应趋势。切到 2023 年空周期，确认不复用其他年份数据。
9. 切换到无数据月份，查看空状态；刷新页面确认数据与预算仍保留。图表周期为本次会话状态，刷新默认本月；带 `#charts-year` 链接则默认年图。

## 7. Android 交接建议

原型阶段先约定独立领域层：金额解析、周/月/年范围、日/月聚合、历年收支、分类聚合、均值分母、预算计算、备份校验。网页 `stats.js` 负责图表页面，`domain.js` 负责周期和计算。后续原生实现采用 Java `Ledger` + SQLite + 原生 View，总览、图表、预算共用账本快照，具体文件与环境见《05-Android开发与打包说明》。

需重点测试的不是按钮是否存在，而是记录跨月编辑、恢复中断、重复保存、非法备份与预算分配约束。原型中金额计算/导入校验已有可复用规则，但 JavaScript 实现不能直接视为 Android 生产代码。

本文件记录 v0.2 网页原型的设计和验证边界。项目现已新增 Android Gradle 工程及 0.1.0 调试 APK；按用户要求未安装测试。本文中的浏览器截图与交互结果不能作为原生应用的真机验证结果。后端、商店发布及真实支付授权不在首版范围内。
