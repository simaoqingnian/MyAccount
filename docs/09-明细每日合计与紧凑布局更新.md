## 2. 每日日期右侧增加收支合计

每个日期分组左侧显示日期，当天保留“今天”标记；右侧分两行显示“支出 ¥…”和“收入 ¥…”，金额保留两位小数。某一类型没有记录时显示 0.00，不将收入与支出相减成一个含义不明的金额。

每日合计与当前列表范围一致，遵循所选月份、收支类型、类别、备注关键词和日历日期筛选。只筛选支出时当天收入显示 0.00；清除筛选后恢复完整范围。隐藏金额时，每日合计、筛选合计及其无障碍描述一同遮罩。

合计先对全部符合条件的账目按日期聚合，再显示前 80 笔。因此同一天超过 80 笔、部分账目尚未点击“继续加载”时，当天合计仍包含该天全部符合条件的记录。新增、修改、删除后重新读取并汇总；跨日修改会刷新原日和新日的合计。金额使用整数分累加。

图表下钻明细共用按日列表，因此也显示当前下钻范围的每日合计。

## 3. 明细页布局收紧

| 区域 | 调整 |
|---|---|
| 标题栏 | 从 65dp 收紧为 56dp；标题字号从 24sp 调整为 21sp |
| 月份选择 | 移入标题栏，与标题、“＋”同行，省去独立月份行及其下方 12dp 间隔 |
| 搜索与日历 | 搜索框与日历 / 列表切换图标同行，保留 48dp 点击区域 |
| 收支与类别 | “全部 / 支出 / 收入”与类别筛选放在同一行，省去独立控制行；长类别名省略显示，完整名称可由无障碍描述及选择器读取 |
| 搜索下方 | 间隔从 10dp 减为 6dp |
| 筛选合计 | 显示笔数、支出、收入；仅存在筛选条件时显示“清除筛选”，未筛选时不占用该按钮的高度 |
| 日期分组 | 首日上边距从 18dp 减为 4dp，后续日期为 10dp；每日收支在日期右侧显示 |
| 账目行 | 最小高度从 68dp 减为 60dp，上下内边距从 12dp 减为 8dp；41dp 图标容器保留 |
| 内容边距 | 左右从 22dp 减为 18dp，底部从 24dp 减为 16dp |

以上布局尺寸是代码设置值；实际可见行数受屏幕、系统栏、字体和账目内容影响，本轮未做设备显示测量。
