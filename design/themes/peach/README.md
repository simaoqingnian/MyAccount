## 设计方向

用奶油白背景、柔桃粉卡片、淡杏色按钮和少量开心果绿，营造柔软的纸品感。主要文字采用可可棕，保持金额和账目清楚；分类图标延续现有线性图标，增加圆润底色与选中标记。桃子小表情放在余额卡或图表汇总卡的空余角落，不覆盖数字，不进入每一行账目。

| 元素 | 设计 |
|---|---|
| 背景 | `#FFF9F2` 奶油白 |
| 正文与金额 | `#49392F` 可可棕 |
| 次要文字 | `#7D6A5B`，避免低对比的浅粉文字 |
| 卡片与选中项 | `#F9DED0` / `#F5C4B4` 柔桃粉 |
| 辅助色 | `#F6DFC0` 淡杏、`#DCE8D6` 开心果绿 |
| 主要文字强调 | `#9B5145` 暖陶棕 |
| 品牌点缀 | 原创桃子小表情，数量少、位置固定，无持续动画 |

可爱主要通过配色、圆角和少量表情体现，录入流程继续使用紧凑布局、五列项目、40dp 图标容器、APP 数字键盘、“保存 / 继续”和日期前后按钮。历史备注默认隐藏，点击备注框才显示横向候选。

## 切换与数据

可切换样板的初始默认仍为“钛银”，奶油桃桃是新增可选项；带 `#peach` 的直达链接会直接展示可爱主题。浏览器只记住本样板的外观选择，不读取或修改 Android、原网页原型的账本。样板可体验项目、备注候选、日期和数字键盘，示例保存仅反馈交互效果。

原生主题切换通过保存状态保留金额、备注、项目、日期与筛选条件；通过独立外观偏好保存选择，不改变账目数据库、备份格式和签名。

## 生成来源

使用用户指定的 `gpt-image-2-5-sunburst-local` 本地 helper，先调用 **Images API**，模型明确为 `gpt-image-2.5-sunburst`，请求 `2048x1536`、质量 `high`；服务实际返回 **1448 × 1086**。首次调用成功，未失败重试，也未回退 Responses API。

AI 图中的金额、均值、日期、趋势与占比是视觉示例，不作为业务计算或未来日期的产品规格。浏览器样板和主题令牌可编辑，未将整张 AI 图铺成页面。已构建 0.3.0 APK；按要求未安装到手机或模拟器。
