## 视觉方向

主题名称为“钛银”：用浅银灰底色与水平拉丝表达钛合金、缎面铝的质感；用石墨色文字维持金额的清晰度；选中态和主要动作使用少量香槟金。细高光与低浮雕集中在余额卡、分类图标和按钮上，明细阅读区保持平整。保留叶片品牌符号，不引入硬币、齿轮等额外装饰。

| 元素 | 设计 |
|---|---|
| 页面底色 | `#EEF0F2` 浅银灰 |
| 内容表面 | `#F8F9FA` 雾白 |
| 主要文字 | `#24272B` 石墨色，金额使用等宽数字 |
| 次要文字 | `#606870`，不采用过浅银字 |
| 金属主按钮 | 香槟金渐变，配 `#30251A` 深色文字 |
| 普通文字强调 | `#7A572A`，与浅底保持足够区分 |
| 分类图标 | 沿用原型线性图标体系，40dp 容器，五列排列 |
| 列表项 | 保留单条底部分隔线，不增加左右竖线 |

收入、错误等业务状态仍用独立语义色，香槟金仅表达选择和主要操作。背景拉丝不穿过明细正文，不给金额文字添加反光效果；不使用持续扫光动画。

## 主题切换设计

按本轮理解，以新主题“钛银”为默认主题；现有暖纸色与森林绿主题命名为“青禾绿”，作为可选项保留，并根据追加需求增加“奶油桃桃”可爱主题。入口设计为“我的 → 外观主题”，用带缩略预览的主题卡呈现，当前项带勾选标记。点击即应用并在本机记忆，不增加付费或登录流程。

原生 0.3.0 统一替换总览、明细、记账、图表、预算、设置、弹窗及系统栏的色彩和材质，保留账目数据、筛选与尚未保存的录入内容。主题偏好放入独立设置，不改变 SQLite 表结构、备份格式或签名。

记账布局继续使用五列项目、APP 数字键盘与“保存 / 继续”。历史备注默认隐藏，点击备注框才显示横向候选；金额焦点与备注输入法的既有规则继续保留。浏览器样板可以体验主题切换、项目选择、备注候选、日期前后切换及示例数字键盘，不写入正式账本。
